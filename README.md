# GroupK - تعریف گروه کالا (اندروید + SQL Server)

## ساخت APK با GitHub
1. یک Repository جدید در GitHub بسازید.
2. تمام فایل‌های این پروژه (از جمله پوشه `.github`) را در شاخه main آپلود کنید.
3. تب **Actions** را باز کنید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow بزنید).
4. پس از پایان (حدود ۳ تا ۶ دقیقه)، در پایین صفحه اجرا، بخش **Artifacts** فایل `GroupK-APK` را دانلود کنید.
5. فایل zip را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## تنظیمات برنامه
منوی بالای صفحه اصلی > «تنظیمات اتصال»: آدرس سرور، پورت، Instance، دیتابیس، کاربر و رمز را وارد و «تست اتصال» بزنید.
